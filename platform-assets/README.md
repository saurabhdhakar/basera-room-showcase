# Basera platform icons

## Single source
`assets/branding/basera-original.png` is the exact uploaded 1254×1254 logo. No symbol, wordmark, tagline, colors or typography were redesigned. `basera-square-master.png` replaces only the black presentation corners with the logo's cream background. All shipped small icons derive from this high-resolution source, never from a previously resized icon.

The full logo and its existing tagline are retained, even in tiny favicons. The small tagline cannot be legible at 16 pixels; a symbol-only favicon was deliberately not substituted because the branding must stay unchanged.

## Connected web assets
Both `src/routes/__root.tsx` and `public/basera.html` reference:
- `public/favicon.ico`: 16/32/48 px multi-resolution browser/Windows bookmark fallback.
- `public/icons/favicon-{16,32,48}.png` and `public/favicon.png` (64 px): browser tabs/bookmarks.
- `public/icons/apple-touch-icon.png` (180 px), `apple-touch-icon-167.png`, `apple-touch-icon-152.png`: opaque iPhone/iPad touch icons, also usable by Safari where supported.
- `public/manifest.webmanifest`: retains existing app identity, start URL, scope, theme and display mode.

The manifest selects `public/icons/icon-{192,512}.png` for `any` and separate `public/icons/icon-maskable-{192,512}.png` for `maskable`. All PNG declarations use `image/png`. Maskable artwork fits inside the central 80% diameter circle; the background fills the canvas. Windows/macOS/Android installed PWAs use these manifest icons according to browser support. Firefox desktop has no standard built-in PWA installation flow; its tab/bookmark icons are configured. macOS Safari Add to Dock and iOS/iPadOS Add to Home Screen choose icons according to their OS version. No offline service worker was added for this icon-only request.

## Prepared native Android assets — NOT connected to an Android build
This repository has no `android/`, Capacitor configuration, native application ID, or Android build. The web manifest does **not** configure a native launcher. Do not describe these prepared resources as already installed in an APK/AAB.

`platform-assets/android/res/` contains:

| Density | Legacy launcher / round (px) | Adaptive foreground/background (px) |
| --- | --- | --- |
| mdpi | 48 | 108 |
| hdpi | 72 | 162 |
| xhdpi | 96 | 216 |
| xxhdpi | 144 | 324 |
| xxxhdpi | 192 | 432 |

Each `mipmap-{density}` has `ic_launcher.png`, `ic_launcher_round.png`, `ic_launcher_foreground.png` and `ic_launcher_background.png`. Adaptive foreground is RGBA with transparent outer padding, retaining the original background behind the logo; background is opaque cream. All important artwork is within the Android 66 dp diameter safe circle in the 108 dp adaptive canvas. Additional padding is required by the platform, not decorative. Legacy icons keep the full branding within a circular mask. Android applies round/squircle masks; no fake shadow or badge is baked in.

`mipmap-anydpi-v26/ic_launcher.xml` and `ic_launcher_round.xml` connect the two adaptive layers with `@mipmap` references. Android 13 monochrome themed icons are intentionally not substituted: they would recolor this multicolor brand.

To apply to the **existing** Android app, run from this repository:

```sh
python3 scripts/install-android-icons.py /absolute/path/to/existing/android
```

The installer requires an existing app manifest and Gradle app file, backs up the manifest, copies the resources into `app/src/main/res/`, and sets the application attributes:

```xml
android:icon="@mipmap/ic_launcher"
android:roundIcon="@mipmap/ic_launcher_round"
```

It does not alter Firebase, package/application ID, Gradle config, UI or app features. It refuses activity/alias icon overrides rather than claiming application attributes supersede them. Before release, inspect flavor/debug/release resource and manifest overlays and verify the merged manifest plus final APK/AAB actually use these assets. For updates, keep the existing application ID and signing identity and increase versionCode in that actual project. Launcher refresh behavior depends on the device; no package-ID change is required.

## Google Play
`platform-assets/play-store/play-store-icon-512.png`: 512×512 opaque RGB PNG, under 1 MB, generated from the high-resolution source. Upload separately under Play Console's main store listing graphics; this listing icon is not inferred from the APK launcher icon. Existing logo text is preserved, no new text was added. A feature graphic (1024×500), device screenshots, signed AAB and any policy-required listing materials remain separate; they are not generated by this icon task.

## Verification boundaries
Web paths, MIME responses, head links, image dimensions, adaptive XML references and measured safe zones can be checked in this project. Installer behavior can be checked using a disposable fixture. An actual Android build, installed iPhone/iPad/desktop appearance, Play Console acceptance and existing-user native updates cannot be confirmed without that project/devices/services. Previously installed PWAs may retain cached icons and require removing/re-adding the app; the manifest's identity/start URL/scope were not changed.

See `platform-assets/icon-inventory.json` for every generated raster filename, dimensions and purpose.
